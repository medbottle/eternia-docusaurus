We have a few cosmetic spells that can be used to customize a player's sprite and how it is seen. Below will be some examples as to how set them up properly and adjust to a player's application and/or choice.

# Opacity (alpha_transform)

Often requested by ghosts, spectres, spirit-like entities and so on.

- give them cosmetic toggle buff
- debug, go into spells, choose the cosmetic toggle buff
- alpha_transform set to somewhere between 120-155 (can be higher or lower)

Always prioritize visual clarity!
