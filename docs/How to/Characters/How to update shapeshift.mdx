If someone with **Shapeshift** asks for their age, RPL, or similar to be changed and the normal debug values do not work:

1. Go to **varedit**.
2. Open **list/spells**.
3. Open **shapeshift**.
4. Edit the disguise values (`disguise age`, `disguise rpl`, etc.) under that entry.

These are separate from the character's base stats.
