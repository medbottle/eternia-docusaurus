To unlock rebirth races for a player:

1. **var edit**
2. Find `highest_rpl_reached`
3. Set to **230**.
4. Have them **Zoom in / Zoom out** via **Settings** or `/zoom` to force the game to save.

:::warning
Hotkeys will **not** work for this step — they must use the Settings button or `/zoom`.
:::
