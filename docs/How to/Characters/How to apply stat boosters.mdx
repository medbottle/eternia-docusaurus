When a player requests stat boosters:

:::warning
**Do not** edit the stat directly. **Do not** spawn in boosters.
:::

1. Press **EDIT** -> press **`s`** until you reach **stat points**, and put **50** into the box.
2. Press **VAR EDIT** -> **Ctrl+F** `noperms` and set the variable to **1**.
