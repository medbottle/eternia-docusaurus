:::warning
Always create and edit items in the **breakroom** (`Teleport NPC` -> `.Breakroom`)
:::

## Creating New Items

1. Teleport to `.breakroom`.
2. Use **Edit** to set stats and all item properties.
3. Use **Debug** to switch the equipment slot (see table below).

Hit the **reload circle** when using **Spawn Anything**.

## Large Item Hitboxes

To prevent large items from using a big square hitbox, debug their `mouse_opacity` to **1**.

:::note
This resets on reboot.
:::
