When approving rumors, use the following as a general rule of thumb:

- Is it **anti-climactic**? Witchcraft/hex sightings should be handled through say/RP.
- Overly aggressive or negative rumors should be disputed in RP — give leeway for big public events (executions, etc.).
- Does it challenge basic immersion principles?
